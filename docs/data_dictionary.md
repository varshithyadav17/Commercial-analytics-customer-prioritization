# Data Dictionary

All records are deterministic synthetic examples. They are regenerated by data/generate_data.py using a fixed random seed.

## Input tables

### hcps.csv and hcps_with_segment.csv — one row per HCP

| Field | Meaning |
|---|---|
| hcp_id | Synthetic healthcare-professional key |
| specialty | One of five synthetic specialties |
| region | Synthetic territory/region |
| decile | 1–10 simulated prescribing-decile feature |
| patient_volume | Simulated account-volume feature |
| potential_score | Numeric opportunity score used for segmentation |
| receptivity_score | Numeric receptivity feature used for segmentation |
| rep_id | Assigned representative ID |
| segment | Derived label included only in hcps_with_segment.csv |

Segment thresholds are deterministic: potential >= 60 and receptivity >= 55 is Key Target; potential >= 60 only is Growth; receptivity >= 55 only is Maintain; otherwise Low Priority.

### reps.csv — one row per representative

- rep_id: synthetic rep key.
- rep_name: display label.
- region: representative's assigned region.
- tenure_years: synthetic tenure feature.

### calls.csv — one row per contact event

- hcp_id and rep_id: keys to the HCP and rep tables.
- call_date: ISO date for contact.
- call_type: synthetic contact channel.
- duration_min: simulated contact duration in minutes.

### sales.csv — one row per HCP-month

- hcp_id: synthetic account key.
- month: month-start date.
- rx_volume: simulated monthly volume proxy; not real prescription data.

### rep_targets.csv — one row per representative-quarter with generated actuals

- rep_id: representative key.
- quarter: reporting quarter (for example, 2025-Q1).
- quota_volume: generated target used for the incentive preview.
- actual_volume: synthetic quarterly volume, aggregated from the HCP-month table.

## Generated outputs

| File | Grain | Use |
|---|---|---|
| data/model_outputs/hcps_segmented.csv | HCP | Segment, activity and volume features |
| data/model_outputs/optimized_call_plan.csv | HCP | Actual, target, and planned contact frequency |
| data/model_outputs/segment_summary.csv | Segment | Count, score, volume, and contact summary |
| data/model_outputs/territory_summary.csv | Region | HCP count and descriptive performance proxies |
| data/model_outputs/monthly_trend.csv | Month | Simulated volume trend |
| data/model_outputs/icm_payouts.csv | Representative-quarter | Attainment and illustrative payout |
| sql/query_results/Q1_result.csv through Q5_result.csv | Query-specific | SQL analysis outputs |

## Metric definitions

- Actual calls per month = number of call rows per HCP divided by 12.
- Planned calls per month = coverage floor plus a weighted share of remaining assumed capacity.
- Attainment = actual_volume / quota_volume, with a zero/invalid quota treated as zero attainment for this demo.
- Payout tier = 0% below 80%, 50% from 80% to below 100%, 100% from 100% to below 110%, and 150% from 110% upward.
- Volume per call proxy = aggregated simulated volume divided by contact rows at the matching grain.

All such measures are descriptive examples. None identifies the causal effect of a sales contact.
